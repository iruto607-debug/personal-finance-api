# 💰 Personal Finance Management API

## Overview

A professional REST API built with FastAPI that helps users securely manage their personal finances.

Users can:

- Create an account
- Log in securely
- Track income
- Track expenses
- Categorize transactions
- View financial reports
- Monitor their balance

---

## Project Goals

This project demonstrates backend development skills using modern Python technologies and follows REST API best practices.
