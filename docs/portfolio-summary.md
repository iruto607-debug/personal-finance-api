# Portfolio Summary

This project is a portfolio-ready backend for personal finance tracking, built with FastAPI and SQLAlchemy.

Key strengths:
- Fully tested API with `pytest` coverage and GitHub Actions CI.
- Clean architecture with separate app, database, CRUD, schema, and dependency layers.
- Containerized delivery through Docker and Docker Compose.
- Static frontend demo published via GitHub Pages.
- Ready for backend deployment with Render automation.
- Included Postman collection, seed script, and Kubernetes manifest for real-world demos.

What reviewers will like:
- Clear developer experience: documented setup, deploy instructions, and live demo link.
- Strong portfolio structure: CI, linting, deployment docs, and production-style repo assets.
- Practical API surface with health check, users, and finance endpoints.

Next steps to complete the live portfolio:
1. Enable GitHub Pages on `gh-pages` branch (already deployed).
2. Add Render secrets and deploy the API backend.
3. Optionally add a live API service URL to the README once the backend is deployed.
